# Security Policy

## Supported versions

Only the latest release receives fixes.

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through [GitHub security advisories](https://github.com/longvoquy/Bellator-helper/security/advisories/new). Include the affected version, steps to reproduce, and the impact you expect.

You can expect an initial response within a few days. Confirmed issues are fixed in a new release and credited in the release notes unless you prefer to stay anonymous.

## Scope notes

B-helper runs elevated (Administrator) to read CPU sensors and call the Bellator WMI interface. Reports about privilege escalation, unsafe handling of settings or the scheduled task, and the update checker are especially welcome.
